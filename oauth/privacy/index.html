Privacy Policy

Personal Drive Automation uses Google OAuth to access Google Drive only after explicit authorization by the user.

Google Drive Access

  • The application uses the Google Drive drive.file permission.
  • The application accesses only files and folders created by, or explicitly made available to, the application.
  • The application does not request unrestricted access to all files in the user’s Google Drive.

Use of Google User Data

  • Google user data is used only to perform the requested file automation.
  • Google user data is not sold, rented, or used for advertising.
  • Google user data is not provided to third parties except where required to operate the requested automation or comply with applicable law.

Data Storage

  • Authentication credentials required for the automation may be stored securely by the owner.
  • OAuth credentials and tokens are not exposed publicly.
  • Google Drive content is stored in the user’s own Google Drive account.

Data Retention and Deletion

  • The user controls files stored in Google Drive.
  • The user may delete generated files directly from Google Drive.
  • The user may revoke Google OAuth access at any time through Google Account security settings.

Scope of Use

  • This application is a private automation utility intended for personal use by the owner.
  • It is not provided as a public service to unrelated users.
