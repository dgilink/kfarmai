# kFarmAI 재배가이드·재배달력 공공데이터 설계

## 목적

재배가이드와 재배달력은 사용자가 작물별 관리 흐름을 확인하고, 농업날씨와 공공정보 확인으로 이어지도록 돕는 참고 정보 구조로 운영한다. 실제 API 연동 전에는 검수된 JSON 인덱스를 사용하고, 연동 후에도 fallback 데이터로 유지한다.

## 데이터 출처 후보

- 농촌진흥청_작목별농업기술정보
- 농사로 OpenAPI
- NCPMS 병해충 정보
- 농약안전사용기준
- 기상청 단기예보
- 농촌진흥청_농작업일정 정보
- 농사로 농작업 일정

공공데이터 인증 정보는 문서와 프론트엔드 데이터에 포함하지 않는다.

## API 연동 상태 구분

- 실제 연동: KAMIS 시세, NCPMS 병해충검색
- 연동 구조 준비: 기상청 단기예보
- 확장 예정: 농약·비료 판매업체 표준데이터, aT 공영도매시장 경매정보, 병해충 발생/예찰정보, 농약안전사용기준
- 정적 참고 데이터: 재배가이드, 재배달력 일부

화면에서는 “일부 공공데이터는 실제 API로 연동했으며, 나머지는 공식 데이터 기반으로 단계적 확장 중입니다.”처럼 상태를 구분해 표현한다.

## 재배가이드 화면 구조

1. 작물 선택
2. 재배 개요
3. 생육 단계
4. 토양·물관리
5. 병해충 확인
6. 수확·관리
7. 관련 농업날씨
8. 공식 정보 확인

## 재배가이드 데이터 구조

`data/crop-guide-index.json`은 대표 작물의 검수 전 참고 구조를 담는다.

```json
{
  "crop": "고추",
  "category": "과채류",
  "summary": "고추 재배 시 생육 단계, 물관리, 배수, 병해충 확인을 함께 살펴보는 참고 정보입니다.",
  "stages": ["정식 전 토양 상태와 배수 상태를 확인하세요."],
  "soilWater": ["고온기에는 시듦과 토양 수분 상태를 함께 확인하세요."],
  "pestCheck": ["이상 증상은 NCPMS 병해충검색과 공식 정보를 함께 확인하세요."],
  "harvestCare": ["수확 전 과실 표면 변화와 작업 이력을 확인하세요."],
  "relatedWeather": ["고온, 강수, 습도, 풍속 정보를 농업날씨에서 함께 확인하세요."],
  "publicSources": ["농촌진흥청_작목별농업기술정보", "NCPMS 병해충 정보"],
  "notice": "공식 정보를 바탕으로 정리 중인 참고 정보입니다."
}
```

우선 반영 작물은 고추, 토마토, 딸기, 상추, 배추, 마늘, 양파, 벼, 사과, 포도다.

## 재배달력 화면 구조

1. 작물 선택
2. 월별 작업
3. 현재 월 작업
4. 파종/정식/물관리/웃거름/병해충 확인/수확
5. 관련 재배가이드 연결
6. 관련 농업날씨 연결

## 재배달력 데이터 구조

`data/crop-calendar-index.json`은 대표 작물의 월별 확인 흐름을 담는다.

```json
{
  "crop": "고추",
  "category": "과채류",
  "currentMonthTasks": ["고온기 시듦과 토양 수분 상태를 확인하세요."],
  "months": [
    {
      "month": 3,
      "tasks": ["육묘 상태 확인", "정식 전 토양 준비"]
    }
  ],
  "relatedWeather": "고온, 강수, 습도, 풍속을 농업날씨에서 함께 확인하세요.",
  "relatedGuide": "crop-guide.html?crop=고추",
  "publicSources": ["농촌진흥청_농작업일정 정보"],
  "notice": "지역과 품종에 따라 차이가 있을 수 있으므로 공식 정보를 함께 확인하세요."
}
```

월별 작업은 단정형 지시가 아니라 “확인”, “준비”, “참고” 표현을 사용한다.

## 공공데이터 연결 원칙

- 실제 API 연동은 Worker를 통해 처리하고 API 키를 프론트엔드에 노출하지 않는다.
- API 응답 실패 시 `data/crop-guide-index.json`, `data/crop-calendar-index.json`을 fallback으로 사용한다.
- 병해충 관련 내용은 단정하지 않고, 이상 증상이 보이면 NCPMS 공식 정보를 함께 확인하도록 안내한다.
- 농약 관련 내용은 안전사용기준 확인으로 연결하고, 특정 제품 사용을 지시하지 않는다.
- 날씨 정보는 작업 판단의 참고자료로만 표시하고 현장 상태와 공식 정보를 함께 확인하도록 안내한다.

## 화면 연결 흐름

- 재배가이드 → 농업날씨: 작물별 물관리, 강수, 고온, 풍속 확인으로 연결한다.
- 재배가이드 → 재배달력: 선택 작물의 현재 월 작업과 월별 작업으로 연결한다.
- 재배달력 → 재배가이드: 월별 작업에서 작물별 관리 항목을 다시 확인한다.
- 재배가이드/재배달력 → 농자재·관리: 관수·시설자재, 화분·도구, 스마트팜 참고 정보로 연결한다.
- 농자재·관리 → 재배가이드/재배달력/농업날씨: 상황별 품목 확인 뒤 작물별 관리 흐름과 날씨 참고 정보로 이어진다.

## 향후 구현 단계

1. 대표 작물 10종의 JSON 인덱스를 화면에서 선택형으로 표시한다.
2. 농사로 OpenAPI와 농촌진흥청 공공데이터 항목명을 실제 응답 기준으로 매핑한다.
3. NCPMS 병해충 정보와 농약안전사용기준은 공식 정보 확인 카드로 연결한다.
4. 기상청 단기예보는 농업날씨 페이지의 지역 선택값과 연결한다.
5. API 실패 시에도 작물별 기본 가이드와 달력 fallback이 보이도록 유지한다.

## 공식사진 연동 TODO

- 공공기관 공식사진은 출처와 사용 조건을 확인한 뒤 반영한다.
- 농사로, 농업기술포털, 농촌진흥청, 공공데이터 이미지 API 제공 여부를 확인한다.
- 외부 사이트 이미지를 직접 hotlink하지 않는다.
- 사용이 허용된 이미지만 kFarmAI 서버 또는 저장소에 저장한 뒤 사용한다.
- 이미지 출처 표기 구조를 `officialImageUrl`, `officialImageSource`, `officialImageLicenseNote`, `officialImageStatus` 필드와 연결한다.
- 검수 전 이미지는 사용자 화면에 노출하지 않고, 공식 사진 자료는 출처 확인 후 순차 반영 예정이라는 안내만 작게 표시한다.

## 공식 이미지 사용 원칙

- 농촌진흥청, 농사로, 농업기술포털, 지자체 농업기술센터, 공공데이터포털 등 공식기관 자료를 우선 확인한다.
- 공공누리 표시가 있는 자료만 사용 대상으로 검토한다.
- 공공누리 제1유형은 출처표시 조건을 데이터에 남긴 뒤 우선 사용할 수 있다.
- 공공누리 제2~4유형은 상업적 이용 제한 또는 변경 이용 제한이 있으므로 사업화 가능성과 썸네일 가공 여부를 함께 검토하고, 확인 전에는 사용을 보류한다.
- 공공누리 표시가 없거나 사용 조건이 불명확한 이미지는 공식사진으로 표시하지 않는다.
- 이미지 데이터에는 `sourceName`, `sourceUrl`, `licenseType`, `licenseNote`, `usageStatus`를 반드시 남긴다.
- `usageStatus`가 `verified`인 이미지만 화면에 표시하고, `pending` 또는 `blocked` 이미지는 안내 문구만 표시한다.
- 외부 이미지 hotlink는 지양하며, 허용된 이미지는 저장소 또는 kFarmAI 서버에 저장한 뒤 출처를 표기한다.
- 농촌진흥청, 농사로 등 공식기관이 kFarmAI를 후원하거나 제휴한 것처럼 보이지 않게 “출처”로만 표시한다.
