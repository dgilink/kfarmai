# kFarmAI 농산물 시세 고도화 설계

## 목적

농산물 시세 화면은 단편 가격 목록이 아니라 가격 유형별 시장 흐름을 확인하는 참고 정보 화면으로 운영한다. 화면 문구는 실제 거래 판단을 단정하지 않고, 공식 제공처와 현장 조건을 함께 확인하도록 안내한다.

## 현재 한계

- 품목별 단편 가격만 표시되어 가격 유형 구분이 약하다.
- 소매가격, 중도매인 판매가격, 도매가격·경락가격, 친환경 소매가격이 분리되어 있지 않다.
- 품목별 최근 흐름을 그래프로 확인하기 어렵다.
- 현재 가격이 기간 내 어느 정도 위치인지 가늠하기 어렵다.

## 가격 유형

1. 소매가격
   - source: KAMIS
   - 소비자 구입 가격 흐름을 참고한다.
2. 중도매인 판매가격
   - source: KAMIS
   - 도매시장 중도매인 판매가격으로 경락가격과 다를 수 있다.
3. 도매가격·경락가격
   - source: aT 공영도매시장 경매정보
   - 시장, 품목, 등급, 거래일에 따라 차이가 있다.
4. 친환경 소매가격
   - source: KAMIS/공공데이터
   - 조사주기와 품목 범위가 일반 시세와 다를 수 있다.

## KAMIS Open API 활용 원칙

현재 Worker의 기존 `/api/kamis/prices`는 `dailySalesList` action을 사용한다. 공개 문서와 kamispy 참고 자료에서 확인 가능한 action은 다음과 같다.

- `dailySalesList`: 최근일자 도·소매가격정보
- `periodProductList`: 일별 품목별 도·소매가격정보
- 최근 가격추이, 월평균 가격추이, 친환경농산물 가격정보는 문서상 후보이나 실제 운영 키 응답 확인 전에는 임의 호출하지 않는다.

이번 1차 구현에서는 기존 `dailySalesList` 기반 summary와 fallback trend를 제공한다. 기간별 API는 정확한 파라미터 검증 후 다음 단계에서 붙인다.

## aT 경매정보 활용 원칙

`AT_AUCTION_KEY`는 Worker secret으로 준비되어 있으나, 정확한 경매정보 엔드포인트와 파라미터 확인 전에는 가짜 호출을 만들지 않는다. `/api/auction/prices`는 안전한 fallback 응답을 제공하고, 실제 연동은 공식 문서 확인 뒤 진행한다.

## 친환경 소매가격 처리

친환경 소매가격은 실시간성이 낮거나 조사주기가 일반 시세와 다를 수 있다. API 응답 검증 전에는 “친환경 소매가격 참고자료”와 공식 정보 확인 안내를 표시한다.

## Worker API 구조

- `GET /api/kamis/prices`
  - 기존 API 유지
- `GET /api/kamis/price-summary?item=토마토`
  - 4개 가격 유형의 최신 요약을 반환한다.
- `GET /api/kamis/price-trend?item=토마토&type=retail&period=30d`
  - 그래프용 가격 흐름 points와 요약값을 반환한다.
- `GET /api/auction/prices?item=토마토`
  - aT 경매정보 연동 전 fallback 응답을 반환한다.

## 화면 구조

- 목록 화면은 모바일에서 여러 품목이 보이도록 compact card로 유지한다.
- 품목 카드에는 현재 선택한 가격 유형의 대표 가격만 표시한다.
- 4가지 가격 요약과 가격 동향 그래프는 품목 클릭 후 상세 패널에서만 표시한다.
- 그래프는 목록 카드 안에 넣지 않는다.
- 품목 클릭 전에는 그래프를 렌더링하지 않는다.

## 가격 동향 그래프

- 외부 라이브러리 없이 SVG 선 그래프로 표시한다.
- 기간은 7일, 30일, 90일, 1년을 선택할 수 있다.
- 아래 요약값을 함께 표시한다.
  - 최신가
  - 기간 평균
  - 기간 최저
  - 기간 최고
- 기간별 실데이터 API가 검증되기 전에는 기준 가격에서 생성한 fallback points를 사용하고 `fallback` 상태를 응답에 포함한다.

## fallback 원칙

- API 실패 시 빈 화면을 만들지 않는다.
- 데이터가 없으면 “데이터 없음”, “공식 정보 확인”, “준비 중”을 표시한다.
- 기존 저장 데이터와 안내 카드를 유지한다.

## 안전 표현

- KAMIS 및 공공데이터 기반 시장 흐름 참고자료입니다.
- 실제 거래가격은 산지, 규격, 등급, 시장, 판매처에 따라 달라질 수 있습니다.
- 공식 정보를 함께 확인하세요.

## 사용하지 않을 표현

- 최저가
- 가격비교
- 구매하기
- 판매처 추천
- 지금 사세요
- 지금 파세요
- 수익 보장
- 거래 추천

## 향후 구현 단계

1. KAMIS `periodProductList` 파라미터를 운영 키로 검증한다.
2. 기간별 실제 가격 points를 `price-trend`에 연결한다.
3. aT 공영도매시장 경매정보 공식 엔드포인트와 파라미터를 확인한다.
4. 친환경 소매가격의 제공 주기와 품목 범위를 확인한다.
5. 품목 코드, 단위, 등급 필터를 UI에 단계적으로 추가한다.
