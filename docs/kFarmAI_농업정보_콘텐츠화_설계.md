# kFarmAI 농업정보 콘텐츠화 설계

## 목표

농업정보 탭은 공공자료와 연구자료를 단순 링크 목록으로 보여주는 화면이 아니라, 사용자가 보고 싶어지는 콘텐츠형 화면으로 운영한다.

핵심 방향은 다음 두 가지다.

- 농촌진흥청, 농사로, 공공기관, 대학, 연구기관 자료를 쉬운 카드형 콘텐츠로 재가공한다.
- 영상은 YouTube 등 공식 플랫폼의 임베드 방식으로만 제공하고, 파일 다운로드나 재업로드를 하지 않는다.

## 화면 구성

농업정보 탭의 우선 배치는 다음 순서를 따른다.

1. 농업정보 제목과 짧은 설명
2. 오늘의 농업 영상
3. 최신 농업연구동향
4. 이번 주 농업 이슈
5. 재배가이드, 농업날씨, 시세, 달력 등 핵심 바로가기
6. 농자재·관리 카테고리
7. 계산기와 시세 참고

## 영상 큐레이션 원칙

- 영상 파일을 다운로드하지 않는다.
- 영상 파일을 `static` 폴더에 저장하지 않는다.
- 재편집하거나 재업로드하지 않는다.
- YouTube 공식 iframe embed만 사용한다.
- 클릭 전에는 iframe을 로드하지 않고 썸네일만 표시한다.
- autoplay는 기본으로 끈다.
- YouTube 로고와 공식 컨트롤을 가리지 않는다.
- 채널명, 원본 링크, 출처 유형을 함께 표시한다.

## 영상 출처 유형

영상 데이터의 `sourceType`은 다음 기준으로 구분한다.

- `domestic_official`: 국내 공식기관 영상
- `domestic_public`: 국내 공공성 있는 공개 영상
- `domestic_university`: 국내 대학·연구기관 영상 또는 자료
- `overseas_official`: 해외 공식기관 영상
- `overseas_university`: 해외 대학·연구기관 영상
- `overseas_research`: 해외 연구기관 참고 영상

해외 영상은 국내 품종, 기후, 작형과 다를 수 있으므로 `해외 참고`로 분리 표시한다.

## 영상 데이터 상태

- `active`: 화면 표시 가능
- `pending`: 원문, 채널, 사용조건 확인 전
- `hidden`: 운영상 숨김

화면에는 `active`이고 `videoId`가 있는 YouTube 영상만 표시한다.

## 연구동향 재가공 원칙

연구동향은 원문 제목을 그대로 나열하지 않고 사용자가 이해하기 쉬운 질문형 제목과 짧은 요약으로 바꾼다.

카드에 포함할 항목:

- 쉬운 제목
- 2~3줄 요약
- 왜 흥미로운가
- 누가 관심 가질까
- 관련 작물
- 관련 농자재 또는 기술 분야
- 출처

표현은 다음처럼 안전하게 유지한다.

- `도움이 될 수 있습니다`
- `참고할 만합니다`
- `연구 흐름입니다`
- `확인하려는 연구입니다`

아래 표현은 사용하지 않는다.

- 상용화 확정
- 효과 보장
- 최종 처방
- 추천 농약
- 오늘 방제하세요
- 구매 유도

## 대학·연구기관 자료 확장

농업대학, 생명과학대학, 농생물, 농업경제, 생물학 등 대학·연구기관 자료도 확장 대상으로 삼는다.

단, 화면 표시는 다음 조건을 만족할 때만 한다.

- 대학 또는 연구기관 공식 페이지
- 논문 DOI 또는 학술지 원문 링크
- 공식 보도자료 또는 연구성과 페이지
- 저작권과 인용 조건 확인 가능
- kFarmAI 요약이 원문 내용을 과장하지 않음

검수 전 항목은 `pending`으로 저장하고 화면에 표시하지 않는다.

## 출처와 저작권

- 출처명과 원본 URL을 데이터에 남긴다.
- 출처 URL이 정확하지 않으면 빈 값으로 둔다.
- 가짜 링크를 만들지 않는다.
- 공식기관이 kFarmAI를 후원하거나 제휴한 것처럼 보이지 않게 한다.
- 영상과 연구자료의 저작권은 각 제공 기관과 원 게시자에게 있음을 표시한다.

## 향후 자동 수집 계획

자동 수집은 운영자가 검수할 수 있는 대기 상태까지만 수행한다.

권장 흐름:

1. 공식기관, 대학, 연구기관 후보 URL 수집
2. 제목, 날짜, 출처, 원문 링크 저장
3. kFarmAI 요약 초안 생성
4. 사람이 검수
5. `status: active` 전환

검수 없이 자동으로 사용자 화면에 표시하지 않는다.
