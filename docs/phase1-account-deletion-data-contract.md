# Phase 1 계정 삭제 데이터 처리 계약

## 문서 상태와 적용 범위

이 문서는 정식서비스 계정 삭제 요청의 기술 계약과 아직 필요한 운영 결정을 구분한다. Phase 1 코드는 요청 접수까지만 구현하며, Production migration과 Edge Function 배포 전에는 효력이 없다. 공개 개인정보처리방침이나 이용약관을 대신하지 않는다.

상태 표기:

- `확정`: 현재 코드가 따라야 하는 기술·안전 계약
- `대표 결정 필요`: 서비스 운영자가 정책을 선택해야 하는 항목
- `법률/개인정보 검토 필요`: 관련 법령과 실제 처리 목적을 확인해야 하는 항목

## 확정된 요청 접수 계약

1. 로그인 세션의 JWT를 서버에서 검증한 사용자만 계정 삭제 요청을 만들 수 있다.
2. 브라우저가 보낸 `user_id`나 이메일은 식별 근거로 사용하지 않는다.
3. 서버가 `account_deletion_requests`에 `pending` 요청을 저장한 뒤 응답한 경우에만 접수 완료로 표시한다.
4. 서버 저장 실패, 인증 실패, 네트워크 실패에는 성공 메시지를 표시하거나 로그아웃하지 않는다.
5. 동일 사용자의 중복 요청은 `user_id` 유일키를 기준으로 하나의 `pending` 요청으로 병합한다.
6. 요청 접수 단계에서는 Auth 사용자, 프로필, 게시글, 댓글, 사진, 진단 기록을 삭제하거나 익명화하지 않는다.
7. service-role key는 Edge Function 환경변수로만 사용하고 브라우저에는 제공하지 않는다.
8. 실제 삭제·익명화 정책이 승인되기 전에는 요청 상태를 `completed`로 변경하지 않는다.

## 데이터별 처리 계약

| 항목 | 현재 동작 | 정식 처리 전 결정 상태 |
|---|---|---|
| 계정삭제 요청 접수 | JWT 검증 후 서버 요청 큐에 `pending` 저장 | 확정 |
| 처리 예상 기한 | 화면과 정책에 아직 약속하지 않음 | 대표 결정 필요, 법률/개인정보 검토 필요 |
| Supabase Auth 계정 | 접수 단계에서는 유지 | 데이터 처리·보존 예외 확인 후 삭제 시점 대표 결정 필요 |
| 프로필 개인정보 | 접수 단계에서는 유지 | 삭제 또는 비식별화 범위 대표 결정 필요, 법률/개인정보 검토 필요 |
| 공개 게시글 | 자동 변경하지 않음 | 삭제·작성자 익명화·유지 중 대표 결정 필요 |
| 공개 댓글·답글 | 자동 변경하지 않음 | 삭제·작성자 익명화·유지 중 대표 결정 필요 |
| 비밀댓글 | 자동 변경하지 않음 | 본문 삭제 여부와 분쟁 보존 예외 법률/개인정보 검토 필요 |
| 업로드 사진 | Storage 객체를 자동 삭제하지 않음 | 원본·파생 이미지 삭제 시점과 백업 보존 기간 대표 결정 필요 |
| AI 참고진단 기록 | 자동 변경하지 않음 | 개인정보 포함 가능성을 고려한 삭제·보존 기준 검토 필요 |
| 신고·분쟁 기록 | 자동 변경하지 않음 | 처리 완료 및 법적 보존 필요 기간 법률/개인정보 검토 필요 |
| 보안·접속 로그 | 자동 변경하지 않음 | 최소 보존 범위와 기간 법률/개인정보 검토 필요 |
| 요청 취소 | API와 UI 미구현 | `pending` 단계 취소 허용 여부와 방법 대표 결정 필요 |
| 완료 통지 | 미구현 | 이메일 또는 서비스 알림 방식과 발송 시점 대표 결정 필요 |

## 삭제 처리 순서 제안 — 승인 전 실행 금지

정책 승인 후 별도 구현에서 다음 순서를 검토한다.

1. 요청 상태와 본인 확인 유효성을 재검증한다.
2. 신고·분쟁·법적 보존 예외를 확인한다.
3. 승인된 정책에 따라 프로필과 사용자 생성 데이터를 삭제 또는 익명화한다.
4. Storage 원본·파생 객체를 승인된 범위에서 삭제한다.
5. Auth 계정을 삭제한다.
6. 개인식별정보가 없는 처리 증적만 승인된 기간 동안 보관한다.
7. Auth 계정 삭제 전에 확정된 채널로 처리 완료를 통지한다.

## 개인정보처리방침 초안에 반영할 항목

- 계정 삭제 요청의 접수 채널, 본인 확인 방식, 처리 절차와 예상 기한
- 계정 삭제 시 프로필·게시글·댓글·비밀댓글·사진·진단 기록의 처리 방식
- 처리 후에도 보존하는 데이터의 항목, 목적, 법적 근거와 기간
- 백업 데이터의 삭제 또는 격리 기간
- 신고·분쟁·법적 보존 요청이 있는 경우의 예외
- 처리 완료 통지와 문의·이의제기 방법
- 처리 업무를 외부 서비스에 위탁하는 경우 수탁자와 처리 내용

## 이용약관 초안에 반영할 항목

- 탈퇴 전 사용자가 자신의 게시글·댓글을 직접 확인하거나 삭제할 수 있는 범위
- 탈퇴 후 공개 게시글·댓글의 삭제·익명화·유지 정책
- 공동 대화 맥락, 신고·분쟁 중 콘텐츠, 법적 보존 자료의 예외 처리
- 계정 삭제 요청 취소 가능 시점과 이미 완료된 처리의 복구 불가성
- 업로드 사진과 게시물에 대한 이용 허락이 탈퇴 시 어떻게 종료되는지

대표 결정과 법률/개인정보 검토가 완료되기 전에는 공개 문서에 구체적인 처리 기한이나 자동 삭제를 확정적으로 약속하지 않는다.
