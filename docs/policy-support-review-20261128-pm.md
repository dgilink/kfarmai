## 조사 범위·보안

보조금통합포털 공모 화면은 HTTP200으로 열렸으나 정적 응답에 공모 0개/조회 데이터 없음이 표시돼 전체 포털의 공고 부재로 단정하지 않았다. 농식품부 공지 목록 직접 접근은 503이었고 공식 홈페이지/검색의 최신 공고는 11월27일 식품산업 정보분석 전문기관으로 기존 게시와 중복이었다. 기업마당 최신 페이지 역시 기존 등록과 중복이었다. 외부 수집 목록은 발견용으로만 사용했다. 기존 날짜 확인 중 14건 중 10개 기관 본문 재접속 성공, 고성3건과 농정R&D 등 접근 실패는 정부 등록 안내·기존 상충 사유를 유지하며 확인일을 임의로 갱신하지 않았다.
