# V3 Phase 5B-2 공식자료 Source Audit

기준일: 2026-10-04

## 범위와 원칙

이 문서는 `data/agri-official-sources.json`의 운영 계약을 설명한다. Registry에는 공식기관 원문 URL이 확인된 자료만 등록하며, 확인하지 못한 발표일·수정일·공공누리 유형은 추정하지 않는다.

화면과 후속 콘텐츠는 다음 순서를 따른다.

1. 공식자료 근거: 기관명, 실제 자료명, 원문 URL, 확인 가능한 발표일, 확인일
2. kFarmAI 설명: 공식자료의 근거 범위 안에서 자체 재구성한 설명
3. 원문 출처 링크

AI 생성·요약 정보는 공식자료와 구분하고, 커뮤니티 내용은 이용자 경험·의견으로 표시한다. 공식자료 원문을 대량 복제하지 않는다.

## Registry 현황

공식출처 11건을 등록했다.

- 농촌진흥청·농사로: 4건
- 농림축산식품부: 2건
- 해양수산부: 2건
- 국립수산과학원: 3건
- 기타 공공기관: 0건

모든 URL과 기관명, source ID, 확인일을 기록했다. 개별 자료 페이지에서 공공누리 유형 또는 동일한 수준의 이용조건을 확인하지 못했으므로 11건 모두 `license.status = needs-review`다. 이 상태에서는 상업적 이용과 변경 이용 가능 여부를 확정하지 않는다.

## ORP HOLD

ORP는 taxonomy와 검색 보조어로 유지한다. 현재 Registry에는 ORP를 육상양식 대표 핵심지표 또는 독립 콘텐츠로 승격할 수 있는 충분한 공식 1차 근거가 없다.

- evidence level: `supplementary`
- SEO eligibility: `hold`
- 독립 SEO 페이지: 생성 금지
- 다른 수질항목과 같은 수준의 공식 핵심지표 표시: 금지

## SEO eligibility

14개 주제를 `eligible` 후보로 기록했다. 실제 페이지 생성 승인이 아니며, 원문 검토·라이선스 확인·자체 설명 작성이 끝난 뒤 다시 검수해야 한다.

우선순위는 다음과 같다.

1. RAS 순환여과양식
2. 육상양식 수질관리

ORP 독립 페이지는 `hold`다. Phase 5B-2에서는 SEO 페이지를 생성하지 않는다.
