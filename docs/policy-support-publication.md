# 정책·지원 공고 게시 계약

정책·지원 목록은 공식 원문을 검토한 `data/policy-support-notices.json`의 승인 항목으로 생성한다. 사업 유형 시제품 12건은 목록·상세와 공개 산출물에서 사용하지 않는다. 원본 `data/subsidy_programs.json`은 이전 구조 참고용으로 저장소에만 남긴다. 각 공고는 독립적인 `/policy/<slug>.html` 주소, 정적 HTML 제목·본문, canonical, Article 구조화 데이터 및 sitemap 항목을 갖는다. 검색엔진의 실제 색인·순위는 보장하지 않는다.

## 현재 게시 범위

공식 기관 게시물 또는 정부 공식 등록 안내에서 공표 사실·제목·기관·대상·지역·지원내용이 확인된 정책·지원사업 공고를 수록한다. 사용자 승인은 이 공고 범위의 신규·변경 공개에 한정한다. 농업정보 Daily AutoPublish·커뮤니티·Supabase 및 다른 콘텐츠의 승인 Gate는 변경하지 않는다.

마감일이 확인되고 시작일만 불명확하면 시작일을 추정하지 않고 `null`로 둔다. 마감 전 목록은 ‘접수중’, 상세는 빨간색 ‘시작일 원문 확인’으로 표시한다. 마감 다음 날부터 ‘마감’으로 갱신한다.

### 날짜 확인 중 — 2026-11-05 사용자 승인

공표 사실과 지원내용이 검증되었으나 기관 원문 접근 실패 또는 날짜·요일 불일치로 접수 일정을 확정하지 못한 공고도 공개한다. 목록·상세·홈에 주황색(`#9a3412`, 연한 배경 `#fff7ed`) ‘날짜 확인 중’을 일관되게 표시하고, 접수중·접수예정·마감으로 단정하지 않는다. 날짜가 확인되지 않았다는 문구만으로 공표 사실·지원내용이 검증되지 않은 후보를 공개할 수는 없다.

상세 페이지는 ‘신청 기간’ 표 안의 주황색 ‘날짜 확인 중’ 표시만 사용한다. 표 위의 별도 안내 박스와 중복 설명은 넣지 않는다(2026-11-05 사용자 수정 지시). 확인 사유는 데이터에 보존한다.

- `applicationDateStatus: "checking"`, `applicationEnd: null`, 구체적인 `dateCheckReason`을 기록한다. 확인된 시작일만 유지하고 불명확하면 `null`로 둔다. 임의의 미래 마감일이나 게시일을 접수일로 대입하지 않는다.
- 정부 공식 등록 안내로 검증했다면 `verificationUrl`을 함께 제공하고 해당 등록일임을 표시한다. 기관 원문 URL도 유지한다.
- 날짜 확인 중 공고는 전체 및 전용 필터로 검색할 수 있으며 접수중·마감 필터에 섞지 않는다. 홈 최신 3건에도 동일한 상태를 표시한다.
- 공식 일정이 확인되면 날짜·확인일·해시를 갱신하고 확인 중 상태와 사유를 제거한 뒤 목록·상세·홈·sitemap을 함께 재생성한다. 기존 URL은 유지한다.

## 갱신

1. 공식 HTTPS 원문에서 지역, 대상, 지원 내용, 접수 기간·시간과 담당 부서를 대조한다. 첨부 지침을 읽지 못한 항목의 세부 조건은 단정하지 않는다. 같은 제도라도 지자체별 공고와 마감일은 별도로 취급한다.
2. `automation/policy_support_refresh.py` 후보 수집기는 `review_only` 상태를 유지한다. 검증된 정책·지원 공고는 사용자의 범위 한정 자동 공개 승인에 따라 공개 스냅샷에 추가할 수 있다. 날짜 예외는 위 ‘날짜 확인 중’ 계약에만 적용하며, 나머지 검증 실패는 보류한다.
3. 승인한 항목의 `slug`를 고정한다. `sourceHash`는 이 저장소에 기록한 공개 검수 스냅샷(해시 필드 제외)의 SHA-256이다. 원문 파일 바이트의 해시를 의미하지 않는다. 내용이 바뀌면 원문을 다시 확인하고 해시를 갱신한다.
4. `node scripts/pages/build-policy-pages.cjs`로 목록, 상세 HTML, sitemap을 생성한다. 빌드 산출물 검증은 승인 상태·공식 URL·해시·상세 경로를 확인한다. 승인 Gate와 공개 배포 절차는 기존 규칙을 따른다.
5. 신청절차를 농업정보 글로 심층 정리할 때는 원문 첨부 지침을 대조하고 농업정보의 별도 콘텐츠·미디어·승인 Gate를 거친다. 현 공고 상세는 신청 요약과 공식 원문 연결만 제공한다.

브라우저는 공고 API나 비공개 키를 호출하지 않는다. 지원금액·자부담·마감 시간 등은 원문에 확인된 범위만 표시한다.
