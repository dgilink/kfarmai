# kFarmAI 보조사업정보 공공데이터 설계

## 목적

보조사업 정보는 사용자가 지역, 대상, 분야별로 확인해야 할 공공정보를 찾도록 돕는 참고 정보로 운영한다. kFarmAI는 신청 가능 여부를 확정하지 않고, 공식 공고 확인 전 탐색 경로와 확인 포인트를 제공한다.

## 한 번에 가져오기 어려운 이유

- 보조사업은 중앙부처, 광역지자체, 기초지자체, 농업기술센터, 유관기관이 각각 공고한다.
- 같은 유형의 사업도 지역, 작물, 시설 규모, 자부담 조건, 신청기간, 대상 요건이 다를 수 있다.
- 공고문은 게시판, 첨부파일, 엑셀, PDF 등 다양한 형태로 제공되어 구조가 일정하지 않다.
- 신청 접수, 선정, 집행, 정산 정보가 서로 다른 시스템에 나뉘어 있을 수 있다.
- 공고가 수시로 바뀌므로 정적 데이터는 공식 확인 전 참고 정보로만 표시해야 한다.

## 활용 가능한 공공데이터 출처

- 농림축산식품부 농림축산식품분야 보조금 현황: 사업별 국고보조사업 현황과 지원자격, 지원내용 참고
- e나라도움 보조사업현황: 보조사업 현황, 공모사업, 수행단계별 현황 확인
- AgriX 농림사업정보시스템: 농림사업정보와 농림사업 시행지침 확인
- 지자체 농업기술센터 공고: 지역별 신청기간, 대상, 제출서류, 현장 조건 확인
- 스마트팜코리아: 스마트팜 교육, 지원사업, 관련 프로그램 확인

## 단기 구현

정적 JSON과 공식 링크 중심으로 구현한다.

- `data/subsidy_programs.json`에 대표 보조사업 확인 유형을 저장한다.
- 실제 개별 공고 URL이 확인된 항목만 `officialUrl`을 둔다.
- 개별 공고 URL이 없는 항목은 빈 링크를 만들지 않고 `공식 공고 확인 필요` 상태로 표시한다.
- 화면에서는 지역, 대상, 분야 필터를 제공한다.
- 모든 카드에 `신청 전 공식 공고를 확인하세요.` 문구를 표시한다.

## 중기 구현

공공데이터 파일과 API를 주기적으로 갱신하는 구조를 검토한다.

- 농림축산식품분야 보조금 현황 파일을 내려받아 유형별 인덱스로 정제한다.
- e나라도움 보조사업 현황과 공모사업 정보를 카테고리별로 연결한다.
- 지자체 공고는 우선 수동 검수 목록으로 관리하고, 안정화된 출처부터 자동 갱신한다.
- 갱신 실패 시 기존 정적 JSON과 공식 확인 안내를 fallback으로 유지한다.

## 장기 구현

지자체 공고 모니터링과 변경 감지를 검토한다.

- 지자체 농업기술센터 공고 게시판을 지역별로 수집 후보에 등록한다.
- 공고 제목, 신청기간, 대상, 첨부파일, 담당부서를 추출한다.
- 자동 수집 결과는 바로 확정 정보로 노출하지 않고 검수 상태를 표시한다.
- 동일 사업명의 연도별 공고를 연결해 신청기간 변화를 참고할 수 있게 한다.

## 공식 공고 확인 원칙

- kFarmAI의 보조사업 정보는 참고 정보이며 신청 확정 정보가 아니다.
- 신청기간, 대상, 제출서류, 자부담, 선정 기준은 공식 공고를 우선한다.
- 공식 URL이 확인되지 않은 항목은 링크처럼 표시하지 않는다.
- 반영 상태는 `공공데이터 기반 정리`, `공식 공고 확인 필요`, `확장 예정`으로 구분한다.
- 사용자가 다음 확인 경로로 이동할 수 있도록 농업정보 허브, 스마트팜, 시설재배, 농자재·관리, 재배가이드와 연결한다.

## 향후 API·크롤링 검토 계획

1. 농림축산식품분야 보조금 현황 파일을 정기 갱신 데이터로 검토한다.
2. e나라도움 보조사업현황과 공모사업 정보를 분야별 인덱스로 연결한다.
3. AgriX 농림사업 시행지침과 연도별 사업 정보를 확인 경로로 연결한다.
4. 지자체 농업기술센터 공고는 지역별 수집 후보 목록을 만들고, 변경 감지와 수동 검수 흐름을 분리한다.
5. API 키, secret, `.env.local` 내용은 문서와 프론트엔드 코드에 포함하지 않는다.
