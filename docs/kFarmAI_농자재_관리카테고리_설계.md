# kFarmAI 농자재·관리 카테고리 설계

이 문서는 kFarmAI의 농자재·관리 정보를 판매 목록이 아니라 작물 관리와 공식정보 확인을 돕는 참고자료로 구성하기 위한 기준이다.

## 기본 원칙

- 농자재 정보는 구매 유도용이 아니다.
- 특정 제품, 특정 약제, 특정 판매처를 추천하지 않는다.
- 가격비교, 구매하기, 장바구니, 결제 표현을 사용하지 않는다.
- 작물보호제는 농약안전정보시스템, NCPMS, 제품 라벨의 등록정보·안전사용기준 확인 동선으로만 연결한다.
- 비료·토양 정보는 토양검정, 양분상태, 작물 생육단계 확인 중심으로 구성한다.
- 제조사 URL과 지역 판매점 정보는 “공식정보 확인” 또는 “위치 확인”으로만 표시한다.

## 현재 데이터 현황

| 데이터 | 위치 | 상태 | 활용 |
|---|---|---|---|
| 농자재 카테고리 | `data/agri-input-categories.json` | 내부 데이터 사용 가능 | 상토, 종자, 비료, 작물보호, 관수·시설, 화분·도구, 스마트팜 |
| 농자재 의사결정 흐름 | `data/kfarmai-agri-material-flow.json` | 내부 데이터 사용 가능 | AI 참고 진단 후 다음 확인 동선 |
| 농자재 문제 매핑 | `data/agri-material-decision-map.json` | 내부 데이터 사용 가능 | 과습, 잎마름, 흙 문제 등과 농자재 카테고리 연결 |

| KMA 단기예보 | Worker API | 필요 | 실제 호출 성공 | 관수·시설, 스마트팜, 작물보호 | 작업 전 기상 참고자료 |

## 카테고리 구조

`data/agri-input-categories.json`의 각 카테고리는 다음 필드를 우선 사용한다.

- `id`
- `name`
- `summary`
- `subTypes`
- `checkPoints`
- `relatedCrops`
- `relatedProblems`
- `officialDataStatus`
- `officialSources`
- `manufacturerInfoStatus`
- `localStoreInfoStatus`

기존 화면 호환을 위해 `items`, `productGroups`, `checkBeforeUse`, `publicDataLinks`, `regionInfo`, `officialInfo`도 유지한다.

## 카테고리별 처리 원칙

### 상토·배지

- 육묘용, 원예용, 분갈이용, 수도용 등 용도 구분을 우선한다.
- 배수성, 보수성, pH, EC, 사용 목적을 확인하도록 안내한다.
- 특정 제품 추천 없이 제조사 공식 설명 확인으로 연결한다.

### 종자·육묘

- 품종 추천이 아니라 작형, 지역, 파종·정식 시기 확인 중심으로 구성한다.
- 채소종자, 곡류종자, 과수묘목, 육묘용 자재를 구분한다.

### 비료·토양

- 밑거름, 웃거름, 유기질비료, 액비, 미량요소, 토양검정 참고로 구성한다.
- 시비량 단정 금지.
- 농경지화학성 통계정보와 토양검정 공식자료를 향후 연결한다.

### 작물보호

- 농약 추천, 이 약제를 쓰세요, 오늘 방제하세요 표현 금지.
- 농약등록정보, 적용 작물, 대상 병해충, 안전사용기준, 등록취소 정보, 제품 라벨 확인으로만 구성한다.
- NCPMS와 PSIS를 공식확인 동선으로 연결한다.

### 관수·시설자재

- 점적관수, 분수호스, 관수타이머, 하우스 필름, 차광망, 지주대, 유인줄을 구분한다.
- 농업날씨의 기온, 강수, 바람 상태를 함께 확인하도록 연결한다.

### 스마트팜

- 온습도 센서, 토양수분 센서, EC/pH 센서, 자동관수, 환경제어기, 데이터 기록을 구분한다.
- 센서값만으로 단정하지 않고 실제 작물 상태와 함께 확인하도록 안내한다.

### 농기계·안전용품

- 농기계 안전자료, 보호장비, 작업 전 점검, 보관·정비 확인으로 구성한다.
- 농업기계 안전 홍보 자료와 지역 농기계 임대사업소 연결을 향후 검토한다.

## 검색 연동

홈 검색과 농자재 화면 검색은 다음 키워드를 농자재 정보로 연결한다.

- 상토, 육묘용 상토, 분갈이용 배양토, 상토 곰팡이
- 종자, 모종, 육묘, 파종시기
- 비료, 토양검정, 액비, 밑거름, 웃거름, 미량요소
- 작물보호제, 농약등록정보, 안전사용기준, NCPMS
- 관수, 점적관수, 분수호스, 차광망, 지주대
- 스마트팜 센서, EC 센서, pH 센서, 자동관수
- 농기계, 안전용품, 보호안경, 방진마스크

## 이번 반영

- 23개 core 작물의 `publicDataConnections`에 PSIS `농약안전사용기준 확인` fallback 동선을 추가했다.
- 반려식물/실내식물 basic 작물에 내부 `weather-crop-profiles.json` 기반 관리 참고 동선을 추가했다.
- 재배가이드/재배달력 basic 상세에서도 공공데이터 참고 블록이 보이도록 했다.
- 홈 검색 동적 작물 인덱스에 농자재 정보, 상토, 종자, 비료, 관수, 토양검정, 작물보호제, 실내식물 물주기 키워드를 추가했다.
