# kFarmAI 농자재·관리 카테고리 설계

## 목적

농자재·관리 카테고리는 판매 목록이 아니라 작물 관리와 공공정보 확인을 돕는 참고 정보 허브로 운영한다. 사용자는 작물 상태, 재배환경, 지역 판매점, 제조사 공식 정보를 구분해서 확인한다.

## 현재 카테고리 구조

- 종자: 기존 종자회사 정보와 연결
- 작물보호: 기존 작물보호제 회사 및 공공정보 확인 흐름과 연결
- 상토: 기존 상토회사 정보와 연결
- 비료: 기존 비료회사 정보와 연결
- 관수·시설자재: 상황별 확인 가이드 보강
- 화분·도구: 홈가드닝 사용자 중심 가이드 보강
- 스마트팜: 도입 단계와 공식 정보 확인 흐름 보강

## 기존 연동 유지 원칙

종자, 작물보호, 상토, 비료는 이미 회사 링크와 데이터가 연결되어 있으므로 기존 이동 경로를 유지한다. 신규 보강은 관수·시설자재, 화분·도구, 스마트팜에 한정한다.

## 단순 업체목록의 한계

농자재는 같은 품목이라도 재배환경, 면적, 수압, 배수, 시설 규모, 실내 환경에 따라 확인 항목이 달라진다. 따라서 회사 목록만 나열하지 않고 상황별 확인 흐름을 먼저 제공한다.

업체목록은 마지막 확인 단계에 가깝다. 먼저 사용자가 작물 상태, 재배유형, 날씨, 지역 판매점 성격, 제조사 공식정보 성격을 구분할 수 있도록 문제해결 흐름을 우선한다.

## 보강 대상 설계

### 관수·시설자재

- 상황: 자동관수, 점적관수, 하우스 관수, 배수, 차광, 환기, 방풍
- 품목: 점적호스, 스프링클러, PE관, 밸브, 필터, 타이머, 펌프, 차광망, 하우스 필름, 환기자재
- 확인 흐름: 텃밭은 면적과 물 공급 위치, 노지는 수압과 배수, 시설재배는 환기·차광·배수를 함께 확인한다.
- 지역 정보: 전국농약및비료판매업체표준데이터 기반 지역 판매점, 지역 농협 영농자재센터, 시설자재 취급 업체 검수 상태를 분리한다.
- 공식 정보: 제조사 공식 사이트, 협회/기관 공개 목록, 시설자재 품목별 공개 자료를 향후 큐레이션한다.
- 주의: 본사 위치와 실제 납품·설치 가능 지역은 다를 수 있으므로 현장 확인 경로를 함께 둔다.
- 다음 확인 경로: 관련 농업날씨, 관련 재배가이드, 지역 판매점 확인, 공식 제조사 정보 확인

### 화분·도구

- 상황: 분갈이, 배수 문제, 과습, 식물 지지대, 가지치기, 실내 물주기
- 품목: 화분, 받침, 배수망, 마사토, 분갈이삽, 전지가위, 지지대, 분무기, 물조리개
- 식물별 참고: 몬스테라, 다육식물, 허브류, 장미, 스파티필름 등 홈가드닝 식물의 배수, 통풍, 실내 환경을 함께 확인한다.
- 공공정보 연결 후보: 농촌진흥청 실내정원용 식물 OpenAPI, 식물별 광원·물관리·실내환경 정보
- 운영 원칙: 실제 연동 전에는 검증된 링크처럼 보이지 않게 “연동 후보”, “다음 단계”로 표시한다.
- 다음 확인 경로: 관련 홈가드닝 식물 정보, 관련 재배가이드, 관리 체크포인트, 공식 정보 확인

### 스마트팜

- 단계: 온습도 모니터링, 자동관수, 환기·차광 제어, 양액기, 데이터 기록, 통합제어
- 장비: 센서, 제어기, 자동관수, 환기제어, 차광제어, 양액기, CCTV, 데이터 플랫폼
- 공식 정보: 스마트팜코리아 기업현황, 솔루션정보, 지원사업, 교육정보를 공식 확인 경로로 보완한다.
- 지역 정보: 기업 본사 위치와 실제 설치·AS 가능 지역을 구분한다.
- 확인 흐름: 기초 모니터링, 자동관수, 환기·차광 제어, 통합제어로 단계를 나누어 작물과 시설 규모에 맞게 확인한다.
- 다음 확인 경로: 관련 농업날씨, 관련 재배가이드, 스마트팜코리아 기업현황, 스마트팜 솔루션정보, 지원사업 확인

## 데이터 구조 2차 보강

`data/agri-input-categories.json`은 다음 필드를 기준으로 확장한다.

- `situations`: 사용자가 먼저 고를 수 있는 상황
- `items`: 확인할 품목 또는 장비
- `useCases`: 상황별 확인 흐름
- `checkpoints`: 공통 체크포인트
- `regionInfo`: 지역 판매점 확인 기준
- `officialInfo`: 제조사/공식정보 확인 기준
- `cautions`: 확인 전 주의사항
- `relatedActions`: 다음 확인 경로
- `dataSources`: 향후 연결할 공공데이터·공식정보 후보
- `notice`: 판매 유도가 아니라 참고 정보임을 알리는 안전 문구

## 지역 판매점과 제조사 공식정보 구분

지역별 정보는 업체 본사 주소만으로 나누지 않는다.

- 지역 판매점: 주변 농자재 판매점, 농약·비료 판매업체 표준데이터, 주소, 전화번호, 취급품목, 위도·경도 기반 확인
- 제조사/솔루션 본사: 공식 홈페이지, 협회 회원사, 스마트팜코리아 기업정보, 제품·솔루션 공식 정보 확인

화면에서는 “지역 판매점 정보와 제조사 공식 정보는 성격이 다릅니다. 지역 판매점은 위치 기반 확인, 제조사는 공식 제품 정보 확인 용도로 제공합니다.”라는 기준을 유지한다.

지역 판매점 정보는 위치 기반 확인용이고, 제조사 공식 정보는 제품 정보 확인용이다. 두 정보를 한 목록처럼 섞지 않는다.

## 공공데이터 연동 상태 표현

- 실제 연동: KAMIS 시세, NCPMS 병해충검색
- 연동 구조 준비: 기상청 단기예보
- 공공데이터 기반 확장 예정: 농약·비료 판매업체 표준데이터, aT 공영도매시장 경매정보, 병해충 발생/예찰정보, 농약안전사용기준
- 정적 참고 데이터: 농자재·관리 카테고리, 재배가이드, 재배달력 일부

화면에서는 모든 항목이 연동된 것처럼 표현하지 않는다.

## 공공데이터 활용 범위

- 전국농약및비료판매업체표준데이터: 지역 판매점 확인 기반
- 협회/기관 공개 목록: 제조사와 공식 정보 확인 기반
- 스마트팜코리아 공개 정보: 스마트팜 기업현황, 솔루션정보, 지원사업, 교육정보 확인 기반

## 큐레이션 원칙

- 빈 링크를 만들지 않는다.
- 공식 URL이 검증되지 않은 항목은 링크처럼 표시하지 않는다.
- 신규 카테고리는 “시제품 일부 반영”, “향후 보완 예정”, “공식 정보 확인” 문구를 사용한다.
- 지역 판매점과 제조사 본사는 성격이 다르므로 같은 목록으로 섞지 않는다.

## 사용하지 않을 표현

- 가격비교
- 최저가
- 장바구니
- 결제
- 전화주문
- 추천 농약
- 이 농약을 쓰세요
- 정확한 진단
- 최종 처방

## 향후 구현 단계

1. 관수·시설자재, 화분·도구, 스마트팜의 공식 데이터 출처를 검증한다.
2. 지역 판매점은 위치 기반 확인, 제조사 정보는 공식 제품 정보 확인으로 분리해 표시한다.
3. 스마트팜코리아와 협회 공개 목록을 카테고리별로 큐레이션한다.
4. 공공데이터 연결 실패 시에도 참고 가이드와 공식 정보 확인 안내가 보이도록 fallback을 유지한다.
