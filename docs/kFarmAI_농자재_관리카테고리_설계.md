# kFarmAI 농자재·관리 카테고리 설계

## 목적

농자재·관리 카테고리는 판매 목록이 아니라 작물 관리와 공공정보 확인을 돕는 참고 정보 허브로 운영한다. 사용자는 작물 상태, 재배환경, 지역 판매점, 제조사 공식 정보, 보조사업 공고 확인 경로를 구분해서 확인한다.

## 카테고리 구조

- 작물보호
- 토양·배지
- 비료·액비
- 종자·육묘
- 관수·시설환경
- 홈가드닝
- 스마트팜·시설재배
- 보조사업
- 관련기관

## 운영 원칙

- 농자재 판매가 아니라 작물 관리와 공공정보 확인을 돕는 참고 정보로 표현한다.
- 특정 제품, 특정 농약, 특정 판매처를 추천하지 않는다.
- 상거래 기능처럼 보이는 표현을 사용하지 않는다.
- 지역 판매점 정보와 제조사 공식 정보는 성격이 다르므로 같은 목록처럼 섞지 않는다.
- 보조사업 정보는 신청 확정 정보가 아니라 공식 공고 확인 전 참고 정보로 제공한다.

## 기존 연결 유지

종자, 작물보호, 상토, 비료는 기존 회사 링크와 데이터가 연결되어 있으므로 기존 이동 경로를 유지한다. 신규 보강은 관수·시설환경, 홈가드닝, 스마트팜·시설재배, 보조사업 연결에 집중한다.

## 공식 사이트 링크 1차 반영

관수·시설자재, 화분·도구, 스마트팜 카테고리에 제조사 공식 사이트 확인용 링크를 1차 반영한다. 이 링크는 판매 유도 목적이 아니라 제품 사양, 취급 품목, 공식 자료를 확인하기 위한 참고 정보다.

- 화분·도구: 데코코리아(구 데코플라자), 심폴
- 관수·시설자재: 풍성주공, ㈜경농(아쿠아스마트)
- 스마트팜: ㈜우성하이텍, 신한에이텍㈜

지역 판매점 정보와 제조사 공식 사이트 정보는 성격이 다르다. 지역 판매점은 위치 기반 확인과 주변 취급처 확인에 사용하고, 제조사 공식 사이트는 제품 정보와 공식 자료 확인에 사용한다.

## 관수·시설환경

- 상황: 자동관수, 점적관수, 배수, 차광, 환기, 보온, 하우스 필름, 시설 고온
- 확인 흐름: 텃밭은 면적과 물 공급 위치, 노지는 수압과 배수, 시설재배는 환기·차광·배수를 함께 확인한다.
- 지역 정보: 지역 판매점, 지역 농협 영농자재센터, 시설자재 취급 업체 검수 상태를 분리한다.
- 공식 정보: 제조사 공식 사이트, 협회·기관 공개 목록, 시설자재 품목별 공개 자료를 향후 큐레이션한다.
- 보조사업 연결: 시설원예 현대화, 시설재배 에너지 절감, 농자재 구입 지원 확인 유형으로 연결한다.
- 공식 사이트 확인: 풍성주공과 ㈜경농(아쿠아스마트)을 1차 공식 정보 확인용 링크로 반영한다.

## 홈가드닝

- 상황: 화분 배수, 실내 광량, 과습, 분갈이, 상토 선택, 액비 희석
- 확인 흐름: 식물 증상, 환경, 물관리, 배지 상태를 먼저 확인한 뒤 필요한 도구와 공식 참고 정보를 본다.
- 공공정보 연결: 홈가드닝은 공공데이터가 제한적이므로 재배가이드, 계산기, 커뮤니티 참고 질문과 함께 보여준다.
- 보조사업 연결: 일반 보조사업 대상이 아닐 수 있으므로 홈가드닝 관련 항목은 교육·재배기술 참고 정보로 제한한다.
- 공식 사이트 확인: 데코코리아(구 데코플라자)와 심폴을 1차 공식 정보 확인용 링크로 반영한다.

## 스마트팜·시설재배

- 단계: 기초 모니터링, 자동관수, 환기·차광 제어, 통합제어
- 장비군: 센서, 제어기, 자동관수, 환기제어, 차광제어, 양액기, CCTV, 데이터 플랫폼
- 확인 흐름: 작물, 시설 규모, 설치 환경, 운영 인력, 유지관리 조건을 먼저 확인한다.
- 공식 정보: 스마트팜코리아, 농림축산식품부 보조금 현황, 지자체 농업기술센터 공고를 확인 경로로 둔다.
- 보조사업 연결: 스마트팜 시설 보급, 시설원예 현대화, 시설재배 에너지 절감 확인 유형으로 연결한다.
- 공식 사이트 확인: ㈜우성하이텍과 신한에이텍㈜을 1차 공식 정보 확인용 링크로 반영한다.

## 보조사업 연결

보조사업 정보는 `subsidy-calendar.html`에서 지역, 대상, 분야별로 탐색한다.

- 스마트팜 관련 보조사업 → `mfg.html?category=smartfarm`
- 시설원예 관련 보조사업 → `mfg.html?category=irrigation`
- 재배기술 교육 → `crop-guide.html`
- 농기계·자재 지원 → `mfg.html`
- 병해충 방제 지원 → `public-data.html`

보조사업 카드에는 사업명, 지역, 대상, 분야, 지원내용 요약, 신청기간, 제공기관, 출처, 상태, 공식 확인 버튼을 둔다. 공식 공고 URL이 없는 경우 빈 링크를 만들지 않고 `공식 공고 확인 필요` 상태로 표시한다.

## 데이터 구조

보조사업은 `data/subsidy_programs.json`에서 다음 필드를 사용한다.

- `id`
- `title`
- `region`
- `city`
- `target`
- `category`
- `summary`
- `supportType`
- `period`
- `agency`
- `sourceType`
- `sourceName`
- `officialUrl`
- `status`
- `relatedLinks`
- `notice`

유형별 인덱스는 `data/support-program-index.json`에서 관리한다.

- `category`
- `description`
- `relatedPages`
- `publicSources`
- `notice`

## 공공데이터 활용 범위

- 농림축산식품부 농림축산식품분야 보조금 현황: 사업별 보조금 현황과 지원자격 참고
- e나라도움 보조사업현황: 보조사업 현황과 공모사업 확인
- AgriX 농림사업정보시스템: 농림사업정보와 시행지침 확인
- 지자체 농업기술센터 공고: 지역별 신청기간, 대상, 제출서류, 담당기관 확인
- 스마트팜코리아: 스마트팜 교육과 지원사업 확인

## 화면 표현 원칙

- `공공정보 확인`, `공식 공고 확인`, `기관별 조건 확인`, `참고 정보` 표현을 우선 사용한다.
- `신청 전 공식 공고를 확인하세요.` 문구를 보조사업 카드에 표시한다.
- `공공데이터 기반 정리`, `공식 공고 확인 필요`, `확장 예정` 상태를 구분한다.
- 사용자가 다음 행동을 확인할 수 있게 재배가이드, 농업날씨, 농자재·관리, 공공정보 확인 페이지로 연결한다.
- 제조사 링크는 `제조사·공식 사이트 확인`, `공식 사이트 확인`, `제조사 공식 정보`, `공식 정보 확인용 링크` 문구를 사용한다.
- 판매 유도와 상거래 기능은 현재 범위에서 제외한다.
- 향후 업체 목록은 공공데이터, 협회 목록, 공식 사이트, 사용자 제보를 기반으로 검수 후 확장한다.

## 사용하지 않을 표현

상거래 기능처럼 보이는 문구, 신청·선정 결과를 확정하는 문구, 특정 농약 사용을 지시하는 문구는 사용하지 않는다.

## 향후 구현 단계

1. 보조사업 정적 JSON을 공식 출처별로 주기 검수한다.
2. 농림축산식품분야 보조금 현황 파일과 e나라도움 보조사업 현황을 유형별로 매핑한다.
3. 지자체 농업기술센터 공고를 지역별 후보 목록으로 만들고, 자동 수집 전 수동 검수 기준을 세운다.
4. 공식 링크가 확인된 항목만 외부 링크로 노출한다.
5. API 또는 크롤링을 도입하더라도 API 키, secret, `.env.local` 내용은 프론트엔드와 문서에 포함하지 않는다.
